# 技能配置与命中规则

本文档说明应用内 JSON Skill 的配置方式，以及自动命中规则。这里的 Skill 是应用内能力，不是 Codex Skill；它不会执行 JS 代码，只会导入预设提示词、参数和可选 API 配置。

## 配置入口

静态 Skill 放在 `public/skills/` 目录中，并在 `public/skills/index.json` 登记：

```json
{
  "skills": [
    "pre-project-visual-baseline.json"
  ]
}
```

应用启动时会读取 `public/skills/index.json`，再逐个加载登记的 JSON 文件。修改静态 Skill 后，刷新页面即可重新加载；生产部署时需要重新构建或重新部署静态资源。

也可以在设置页的 Skill 标签中粘贴或选择 JSON 文件导入。手动导入会立即写入本地配置。

## 基本结构

```json
{
  "schema": "gpt-image-playground.skill.v1",
  "id": "pre-project-visual-baseline",
  "name": "项目视觉基准询问",
  "version": "1.0.0",
  "description": "开始视觉项目前先确认色调基准与尺寸比例。",
  "presets": [
    {
      "id": "ask-visual-baseline",
      "name": "前置询问：色调与尺寸",
      "mode": "agent",
      "triggers": ["移动端", "登录页", "UI"],
      "autoApply": true,
      "promptMode": "prepend",
      "prompt": "在开始执行视觉相关任务前，先检查用户是否已经提供色调基准与尺寸比例。"
    }
  ]
}
```

## Skill 字段

`schema`：当前固定使用 `gpt-image-playground.skill.v1`。

`id`：Skill 的唯一标识。同一个 `id` 再次导入时会替换旧 Skill。

`name`：展示名称，也可作为无 `triggers` 且 `autoApply: true` 时的兜底匹配词。

`version`：版本号，用于展示和人工识别。

`description`：说明文本，可选。

`presets`：预设列表。至少需要一个有效 preset。

`customProviders`、`profiles`：可选。用于随 Skill 导入自定义供应商和 API 配置。

## Preset 字段

`id`：preset 的唯一标识，在同一个 Skill 内不能重复。

`name`：展示名称，也可作为无 `triggers` 且 `autoApply: true` 时的兜底匹配词。

`description`：说明文本，可选。

`mode`：适用模式，可填 `gallery`、`agent` 或 `all`。不填或非法值会按 `all` 处理。

`triggers`：自动触发词数组。只要用户输入中包含任一触发词，就可以命中该 preset。

`autoApply`：是否参与自动应用。存在 `triggers` 时默认参与自动应用；若明确写 `false`，即使命中触发词也不会自动应用。没有 `triggers` 时，只有写 `true` 才会进入兜底匹配。

`promptMode`：提示词合并方式，可填 `replace`、`append`、`prepend`。不填或非法值会按 `replace` 处理。

`prompt`：要写入输入框的提示词。自动应用时会按 `promptMode` 合并。

`params`：要覆盖的生成参数，可选。

`profileId`：要切换到的 API 配置 id，可选。只有当前设置中存在该 profile 时才会切换。

## 自动命中时机

自动 Skill 不会在输入时立刻触发，只会在用户提交时触发：

`gallery` 模式：点击生成图片或提交画廊任务时触发。

`agent` 模式：提交 Agent 消息时触发。

触发发生在真正发请求之前。命中后应用会为本次请求临时生成 effective prompt、参数和可选 API 配置，然后再继续原本的提交流程。自动应用不会把 Skill prompt 写回输入框，也不会把它保存成 Agent 历史消息。

## 自动命中规则

1. 先读取当前输入框的 prompt。prompt 去掉首尾空白后为空，则不命中任何 Skill。
2. 只检查当前模式可用的 preset。`mode: "gallery"` 只在画廊生成中可用，`mode: "agent"` 只在 Agent 中可用，`mode: "all"` 两边都可用。
3. 按已安装 Skill 的顺序、每个 Skill 内 preset 的顺序依次检查。
4. 如果 preset 有 `triggers`，并且 `autoApply` 不是 `false`，则检查用户输入是否包含任一 trigger。
5. 如果 preset 没有 `triggers`，只有 `autoApply: true` 时才会用 Skill 名、preset 名、Skill id、preset id 做兜底匹配。
6. 第一个命中的 preset 会被应用，后续 preset 不再继续检查。

匹配方式是确定性的子串匹配，不是语义匹配。应用会把用户输入和 trigger 都转成小写后比较，所以英文大小写不敏感；但不会自动去掉空格、标点，也不会做同义词扩展。

例如当前输入是：

```text
生成一个移动端登录页UI
```

如果 preset 的 `triggers` 包含 `移动端`、`登录页`、`移动端登录页` 或 `UI`，就会命中。若只配置了 `前端 UI`、`界面设计`、`落地页`，则这句话不会命中，因为这些词没有作为完整子串出现在输入中。

## 应用规则

命中 preset 后，应用会为本次请求合并 prompt 和参数：

`promptMode: "replace"`：用 preset 的 `prompt` 替换当前 prompt。

`promptMode: "append"`：把 preset 的 `prompt` 追加到当前 prompt 后面。

`promptMode: "prepend"`：把 preset 的 `prompt` 插入到当前 prompt 前面。

如果当前 prompt 已经包含同一段 preset prompt，则不会重复插入。自动应用产生的 prompt 只用于本次请求；手动点击 Skill 按钮仍会直接修改输入框。

Agent 历史构造时会剥离旧版本自动应用曾写入历史的整段 Skill prompt。剥离只针对当前已安装且可自动应用的 Skill preset prompt，用于避免旧会话在后续每轮请求中反复携带同一段自动 Skill 内容。

`params` 会覆盖当前同名参数。当前支持的参数包括：

```json
{
  "size": "1024x1024",
  "quality": "high",
  "output_format": "png",
  "output_compression": 90,
  "moderation": "auto",
  "n": 1,
  "transparent_output": false
}
```

参数会被清洗到应用支持的范围内。例如 `n` 会限制在 `1` 到 `10`，`output_compression` 会限制在 `0` 到 `100`。

## 触发词配置建议

为中文任务配置 trigger 时，建议同时写“动作词”和“对象词”：

```json
"triggers": ["生成图片", "图片编辑", "移动端", "登录页", "页面设计", "UI"]
```

为具体场景配置 trigger 时，建议写用户可能直接输入的短语：

```json
"triggers": ["移动端登录页", "注册页面", "App 页面", "H5", "小程序"]
```

如果希望 Skill 更保守，减少误触发，就使用更完整的短语，例如 `移动端登录页`。如果希望覆盖面更大，可以加入较短的词，例如 `UI`、`网页`、`海报`。较短的词更容易命中，也更容易误触发。

如果只希望用户手动点击 Skill 按钮应用 preset，可以不写 `triggers`，并且不要写 `autoApply: true`。

## 当前视觉基准 Skill 示例

当前 `public/skills/pre-project-visual-baseline.json` 的 preset 使用：

```json
{
  "mode": "agent",
  "triggers": [
    "图片生成",
    "生成图片",
    "图片编辑",
    "改图",
    "视觉设计",
    "UI",
    "前端 UI",
    "移动端",
    "移动端 UI",
    "移动端登录页",
    "登录页",
    "登录页面",
    "注册页",
    "注册页面",
    "App 页面",
    "应用页面",
    "H5",
    "小程序",
    "原型",
    "页面设计",
    "界面设计",
    "落地页",
    "网页",
    "首屏",
    "海报",
    "封面",
    "banner",
    "品牌视觉",
    "logo",
    "插画",
    "配色",
    "色调",
    "尺寸比例"
  ],
  "autoApply": true,
  "promptMode": "prepend"
}
```

因此，在 Agent 模式输入 `生成一个移动端登录页UI` 并提交时，会因为包含 `移动端`、`移动端登录页`、`登录页` 和 `UI` 而自动命中。命中后会把“确认色调基准与尺寸比例”的提示词临时前置到本次请求中，再提交给 Agent；聊天记录中仍保存用户原始输入。

如果同样的输入发生在画廊生成模式中，不会命中该 preset，因为它配置的是 `mode: "agent"`。
